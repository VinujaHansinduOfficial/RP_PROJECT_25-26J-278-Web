# MindSense AI

A comprehensive AI-powered platform for student well-being and academic success, featuring early identification of at-risk students, burnout detection, on-device AI summarization, and facial emotion recognition with personalized interventions.

## 🌐 Live Demo

Visit the live application: [https://rp-project-25-26-j-278-web.vercel.app/](https://rp-project-25-26-j-278-web.vercel.app/)

## 📋 Features

- **Early Identification via Time-Series Forecasting**: Uses LSTM and ARIMA models to predict student performance trends
- **Student Burnout Detection & Intervention**: Machine learning algorithms to identify burnout patterns and provide timely interventions
- **On-Device AI Summarization**: Real-time summarization of text and behavior data
- **Facial Emotion Detection**: Personalized interventions based on emotional state recognition

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Styling**: CSS3 with custom variables
- **Deployment**: Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd mindsense
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will open at [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
npm run build
```
